Rechtlicher Hinweis zur Prüfung: Einzelne deutsche Gerichte (u. a. LG München I, Urteil vom 20.01.2022, Az. 3 O 17493/20) haben die Einbindung von Google Fonts direkt über Google-Server ohne vorherige Einwilligung der Nutzer als datenschutzrechtlich unzulässig bewertet, da hierfür regelmäßig keine ausreichende Rechtsgrundlage vorliegt. Um dieses Risiko vollständig auszuschließen, empfehlen wir, die Schriftdateien künftig lokal vom eigenen Server auszuliefern (Self-Hosting), statt sie extern von Google laden zu lassen — technisch ohne Aufwand umsetzbar. Bitte vom Anwalt bewerten lassen, ob die aktuelle Einbindung so vertretbar ist oder vor Livegang umgestellt werden sollte.

6. Konfigurator: Anfragen & PDF

Eure Auswahl im Konfigurator (Basisausbau, Extras, Mengen, Varianten, Notiz) kann technisch über die localStorage-Funktion eures Browsers zwischengespeichert werden. Diese Daten verbleiben ausschließlich lokal auf eurem Gerät, werden nicht an uns oder Dritte übertragen und können jederzeit über die Browser-Einstellungen gelöscht werden. Aktuell ist diese Wiederherstellung deaktiviert — die Seite startet bei jedem Aufruf leer.

Die Zusammenfassung eurer Konfiguration könnt ihr euch als PDF herunterladen. Die Datei wird vollständig lokal in eurem Browser erzeugt (mittels der von unserem eigenen Server ausgelieferten JavaScript-Bibliothek jsPDF); dabei findet keine Übertragung an uns oder Dritte statt.

Der Button „Anfrage per E-Mail senden" öffnet, wie beim Kontaktformular, euer eigenes E-Mail-Programm mit einer vorausgefüllten Nachricht — auch hier erfolgt keine automatische Übertragung an einen Server dieser Website.

Der Button „Anfrage per WhatsApp senden" öffnet je nach Gerät die WhatsApp-App oder WhatsApp Web mit einer vorausgefüllten Nachricht an unsere Geschäftsnummer; auf mobilen Geräten kann die PDF-Datei zusätzlich über die Web-Share-Funktion eures Betriebssystems als Anhang mitgegeben werden. Der Versand erfolgt erst, wenn ihr die Nachricht in WhatsApp aktiv abschickt.
